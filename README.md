# Zutan Scribes BattleScribe Repository

This repository installs the fan-made `(HH V1) Zutan Scribes - Deep Water Ambush` catalogue into BattleScribe 2.03.

## Required game system

- Game system: `(HH V1) Warhammer 30,000 - The Horus Heresy`
- Game-system ID: `ca571888-56a9-c58e-ddaf-54f4713538bc`
- Required game-system revision: `165`

Install that Horus Heresy 1.0 game system before installing the Zutan catalogue. It is not duplicated in this repository.

## Upload the repository

1. Extract `Zutan_Scribes_BattleScribe_Repository.zip`.
2. Create a public GitHub repository.
3. Upload these four files to the repository root:
   - `index.bsi`
   - `index.xml`
   - `Zutan_Scribes_Deep_Water_Ambush_HH1.catz`
   - `README.md`
4. Ensure the default branch is named `main`.
5. Copy this URL and replace the placeholders with your GitHub username and repository name:

   `https://raw.githubusercontent.com/YOUR-USERNAME/YOUR-REPOSITORY/main/index.bsi`

## Install on a phone

1. Open BattleScribe.
2. Open **Manage Data**.
3. Open the three-dot menu and select **Add Data Index URL**.
4. Paste the raw `index.bsi` URL.
5. Confirm the source and run **Update Data**.
6. Create a new roster using `(HH V1) Warhammer 30,000 - The Horus Heresy`.
7. Select `(HH V1) Zutan Scribes - Deep Water Ambush (Fanmade)`.

If the catalogue does not appear, verify that Horus Heresy 1.0 revision 165 is installed and that the GitHub URL begins with `raw.githubusercontent.com`, rather than the normal GitHub file-view page.
